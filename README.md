# Mini Projeto de Análise de Dados

Projeto desenvolvido para praticar análise de dados utilizando Python, Pandas e Matplotlib, simulando um cenário de negócio com informações de funcionários, clientes e contratos.

---

## 📖 Sobre o Projeto

Neste projeto foram realizadas análises utilizando diferentes bases de dados para extrair indicadores relevantes sobre desempenho da empresa, folha salarial e faturamento.

As análises foram desenvolvidas em um Jupyter Notebook, utilizando técnicas de manipulação de dados, integração de tabelas e visualização gráfica.

---

## 📊 Análises Realizadas

- Folha salarial dos funcionários
- Faturamento da empresa
- Percentual de funcionários envolvidos em contratos
- Quantidade de contratos por área
- Distribuição de funcionários por área
- Ticket médio mensal dos clientes
